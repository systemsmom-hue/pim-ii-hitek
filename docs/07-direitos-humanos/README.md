# Direitos Humanos e Inclusão

Esta seção reúne os conteúdos relacionados à disciplina de **Direitos Humanos e Inclusão** aplicados ao projeto **Sistema de Gestão de Comissões — Hitek Informática**.

O objetivo desta parte é registrar os aspectos do projeto relacionados à inclusão, acessibilidade, respeito aos usuários e uso responsável da tecnologia.

---

## Objetivos da seção

A documentação deverá abordar, de acordo com o que for desenvolvido na disciplina:

- acessibilidade no uso do sistema;
- inclusão digital;
- respeito à diversidade dos usuários;
- facilidade de utilização;
- apresentação clara das informações;
- uso responsável dos dados;
- tratamento adequado das informações dos usuários.

---

## Relação com o sistema

O Sistema de Gestão de Comissões deverá buscar oferecer uma experiência de uso clara e acessível aos diferentes perfis de usuário.

Entre os aspectos já relacionados ao projeto estão:

- organização clara das funcionalidades;
- boa legibilidade das informações;
- navegação simples;
- separação de acesso por perfil;
- autenticação de usuários;
- acesso somente às funcionalidades autorizadas;
- preocupação com a utilização adequada das informações armazenadas.

---

## Acessibilidade

A acessibilidade também está relacionada aos requisitos não funcionais do sistema.

A interface deverá priorizar:

- textos legíveis;
- identificação clara de campos e funcionalidades;
- organização visual adequada;
- navegação simples;
- apresentação compreensível das mensagens do sistema.

---

## Inclusão

A solução deverá evitar barreiras desnecessárias de utilização.

O sistema deverá ser desenvolvido buscando permitir que seus usuários executem as tarefas previstas de forma simples e compreensível, independentemente do nível de familiaridade com sistemas computacionais.

---

## Uso responsável da tecnologia

O sistema armazenará informações relacionadas a usuários, colaboradores, vendas, comissões e pagamentos.

Por esse motivo, o acesso às informações deverá respeitar as permissões definidas para cada perfil.

Os perfis definidos são:

- Vendedor;
- Financeiro;
- Administrador.

A autenticação e o controle de acesso contribuem para limitar a utilização das informações às pessoas autorizadas.
