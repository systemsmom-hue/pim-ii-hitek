# Redes e Sistemas Distribuídos

Esta seção reúne os conteúdos relacionados à disciplina de **Redes e Sistemas Distribuídos** aplicados ao projeto **Sistema de Gestão de Comissões — Hitek Informática**.

O objetivo desta parte é documentar os aspectos de infraestrutura de rede necessários para o funcionamento da solução.

---

## Objetivos da seção

A documentação de redes deverá apresentar, de acordo com o que for definido no projeto:

- estrutura da rede utilizada;
- equipamentos necessários;
- forma de conexão entre os dispositivos;
- organização da comunicação entre os computadores;
- requisitos de conectividade;
- aspectos relacionados à disponibilidade e acesso ao sistema.

## Relação com o sistema

A infraestrutura de rede deverá permitir que os usuários autorizados acessem o Sistema de Gestão de Comissões e utilizem suas funcionalidades conforme suas permissões.

Os principais perfis que poderão utilizar o sistema são:

- Vendedor;
- Financeiro;
- Administrador.

A estrutura de rede deverá apoiar a comunicação necessária entre os dispositivos utilizados pelos usuários e os recursos onde o sistema e seus dados estiverem disponíveis.
