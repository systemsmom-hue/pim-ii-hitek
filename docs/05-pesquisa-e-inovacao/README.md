## Relação com o projeto

O Sistema de Gestão de Comissões foi proposto a partir da identificação de atividades realizadas de forma manual ou com auxílio de planilhas.

A solução busca aplicar recursos computacionais para organizar e automatizar partes desse processo.

Entre os pontos relacionados à proposta estão:

- centralização das informações;
- automatização de cálculos;
- redução de atividades manuais;
- acompanhamento dos estados das comissões;
- registro estruturado dos pagamentos;
- geração de informações para acompanhamento gerencial.
