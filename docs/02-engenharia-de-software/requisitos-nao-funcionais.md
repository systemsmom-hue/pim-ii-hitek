# Requisitos Não Funcionais

Os requisitos não funcionais definem características de qualidade, restrições e condições que o **Sistema de Gestão de Comissões — Hitek Informática** deverá atender.

---

## RNF01 — Segurança

O sistema deverá proteger o acesso às informações e funcionalidades por meio de autenticação de usuários.

O acesso deverá respeitar o perfil de cada usuário:

- Vendedor;
- Financeiro;
- Administrador.

Cada perfil deverá possuir acesso somente às funcionalidades correspondentes às suas responsabilidades.

---

## RNF02 — Usabilidade

O sistema deverá possuir uma interface simples e de fácil utilização.

As funcionalidades deverão ser apresentadas de forma clara, permitindo que os usuários executem as operações necessárias sem dificuldade excessiva.

As informações mais importantes deverão ser apresentadas de maneira organizada e compreensível.

---

## RNF03 — Desempenho

O sistema deverá apresentar tempo de resposta adequado durante a execução das principais operações.

As consultas e operações comuns deverão possuir tempo de resposta de até **2 segundos**, considerando condições normais de utilização.

---

## RNF04 — Disponibilidade

O sistema deverá permanecer disponível durante os períodos em que for necessário realizar operações relacionadas ao controle de vendas e comissões.

O funcionamento deverá permitir o acesso às informações necessárias para execução das atividades dos usuários.

---

## RNF05 — Escalabilidade

A solução deverá permitir futuras ampliações sem exigir a reconstrução completa do sistema.

A estrutura deverá possibilitar a inclusão de:

- novos usuários;
- novos colaboradores;
- novos registros de vendas;
- novas comissões;
- novas funcionalidades.

---

## RNF06 — Acessibilidade

O sistema deverá buscar apresentar as informações de forma clara e acessível aos usuários.

A interface deverá priorizar:

- boa legibilidade;
- organização visual;
- identificação clara das funcionalidades;
- navegação simples entre as principais operações.

---

## Resumo dos requisitos

| Código | Requisito |
|---|---|
| RNF01 | Segurança |
| RNF02 | Usabilidade |
| RNF03 | Desempenho |
| RNF04 | Disponibilidade |
| RNF05 | Escalabilidade |
| RNF06 | Acessibilidade |
